What it needs

Two spreadsheets hold the data; the pages hold none. A browser needs the key once.

Data
Google Sheets Pin Wei Posting and Pin Wei KOL — the Apps Script behind each page.
Access
A key per browser, from Pin Wei Posting → Open posting helper and Pin Wei KOL → Open KOL site. One link can carry it to another computer.
Bookmarks
PW capture and PW creator, installed once from their install pages below.

Bookmarks

Put them on the Chrome bookmarks bar (Ctrl+Shift+B shows the bar). Each one carries its key, so keep them on Pin Wei computers only.

Share access

One link that opens Posting and KOL on another computer, without the spreadsheets. Whoever opens it can do everything you can, so send it to one person, privately (not in a group chat).

The other person opens the link once; their browser then remembers it. To take access back from everyone, change WEBAPP_TOKEN in that spreadsheet's Script Properties.
